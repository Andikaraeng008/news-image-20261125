One image that sums up Wednesday 25 November 2026: 37 world news stories on a single broadsheet page — three leads, ten secondary stories, a world map with numbered pins, and a date check. Every illustration is drawn from scratch by the program itself (no photos). Text is set in Liberation Serif, bundled in this repo under the SIL Open Font License 1.1 (see FONT-LICENSE.txt); when Pillow is unavailable the program ships the pre-rendered `entry.png` instead, so it still runs on the standard library alone.

## Run it

```sh
python3 main.py
```
